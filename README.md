# InkVoid
> *Ruang arsip digital untuk goresan tanpa rencana.*

## Tentang Proyek Ini
**InkVoid** bukanlah sebuah platform *e-commerce* berskala besar. Proyek ini lahir dari keisengan semata—sebuah tempat singgah yang tenang untuk menyalurkan hobi menggambar, membuat animasi, dan mengeksplorasi kode. 

Web ini berfungsi sebagai galeri sekaligus ruang arsip pribadi untuk berbagai aset digital, mulai dari *sticker pack* bergaya *chibi*, hingga goresan *doodle* dengan estetika *dark* dan *messy* yang sering saya buat di waktu luang. Dibangun dengan antarmuka bernuansa *lo-fi* dan gelap, InkVoid dirancang agar terasa seperti membuka buku sketsa di tengah malam.

## Fitur Sederhana
Karena ini adalah proyek personal, fitur yang disematkan dibuat seringkas mungkin sesuai kebutuhan:
- **Galeri & Arsip Karya:** Menampilkan koleksi aset digital dengan fitur *zoom lightbox* untuk melihat detail gambar.
- **Pemesanan via WhatsApp:** Sistem *checkout* sederhana yang langsung terhubung ke WhatsApp untuk proses verifikasi manual dan pengiriman file.
- **Admin Dashboard:** Ruang di balik layar untuk memantau jumlah pengunjung (*views* & *unique visitors*), serta mengatur status dan harga karya.

## Teknologi yang Digunakan
Proyek ini juga menjadi sarana saya untuk terus belajar dan membiasakan diri dengan teknologi *Full-Stack*:
- **Frontend:** React (Vite) + Tailwind CSS (dikustomisasi dengan palet *Deep Melancholy*).
- **Backend:** Node.js (Express.js) + MySQL.
- **Lainnya:** Integrasi JWT untuk keamanan Admin dan *custom middleware* untuk mencatat statistik kunjungan.
